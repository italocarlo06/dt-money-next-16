# DT Money

Monorepo: `frontend` (Next.js) e `api` (NestJS).

## Desenvolvimento

Na raiz do repositório:

```bash
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000). O front fica em `frontend/`; a API em `api/` (`npm run dev:api`).

## Vercel

Configure o **Root Directory** do projeto Next como `frontend`.
